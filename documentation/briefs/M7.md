## Why this exists

Boss request 2026-10-07 ("draw in 3D scene... browser/3JS") grew into the user's fold-studio design (same day): per-fold direction/angle assignment, material selector (Sheet Metal / ACM with V-grooves), radius field, then "visualize in browser". Two three-persona review loops (UI/UX 7→8, CAD professional 6→8, senior architect 7→8 — artifacts in session log 2026-10-07-M7-plan) converged on the rulings ADR-018 pins. The useful 3D is the FOLDED part — a "did I put the relief on the right corner?" check and a demo win — and because bend angles/directions are NOT in the DXF, the correction loop (assign → callouts → render → fix) IS the feature.

3. **`geometry/fold_model.py` — pure fold math (stdlib only; geometry-tier).**
   - `Pt3` frozen dataclass; Rodrigues axis-angle rotation about an arbitrary 3D axis.
   - Sign-vector classification: point → k-bit key (one bit per fold run, side of run's supporting line; on-line → BFS-parent side). NO planar subdivision. Fold runs via `geometry/runs.chain_run` (after-file's 4-span bend = ONE run — golden-tested).
   - FoldPlan: BFS over flip-one-bit adjacency, rooted at the largest region (tie → lowest eid); each flip = Rodrigues rotation about the fold line in the parent's folded frame; per-run direction (up/down, default up) + angle (default 90°, from `fold_props`).
   - **Per-vertex folding:** every emitted vertex goes through `fold_point` — entities crossing a fold line kink across it. (ADR-018(d); rib-wall-crossing fixture is mandatory.)
   - **M7a geometry = sharp folds:** plate polygons share vertices at fold lines. Pullback `d = R·tan((180°−θ)/2)`, axis offset R, θ, T travel as scene-JSON metadata per fold — NEVER baked into M7a plate vertices (M7b consumes them).
   - Warnings Python-side: box corners (intersecting runs → affected region renders FLAT, ghost-dash, named in `meta.warnings` — no notch synthesis), hems (runs closer than 2·d), through-slot disconnect (same-key duplicate), uncloseable chain → wireframe degrade. Never a silent omission; never a plan failure.
   - `to_scene_json()` → versioned, pure, deterministic (byte-equal on two runs); reads (entities, fold_eids, fold_props, material, units) from the snapshot ONLY; arcs/circles flattened presentation-only.
