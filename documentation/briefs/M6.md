# Brief — M6: Final Preview + Export + Gates

**Files you own:** `dxf_io/export` completion, `ui/export_dialog.py`, `tools/verify_m6.py`, glue in `app.py`.

## Scope (SPEC §5, §11.6, §11.9, ADR-004)

1. **Export pipeline completion** (CONTRACTS §3): fold stage (`rules.folds.resolve_folds`) → layer move → `ezdxf.audit` pre-check (audit failure aborts export with report, human-readable) → version-matched save (`$ACADVER` from header; R2000+ guaranteed at load). Purity: operate on deep copy (ADR-004); idempotency test doubles as regression test here.
2. **Final preview dialog:** before write, render the exact post-export geometry read-only (same canvas class, no interaction) with **OK / Back** buttons only. Back preserves ALL state (pending + applied + folds + flag decisions) — user might just fix the filename (SPEC §11.8.5). Filename field: prefilled `<original>_dogbone.dxf`, source folder, text pre-selected; last-folder memory across session.
3. **Export audit log** (PM R10 acceptance): write `<out>.export_log.md` beside the file — dogbones placed (coords + R), per-entity deletions (eids + type), trims, fold warnings, flagged decisions, audit summary. Summarized in the final dialog.
4. **M6 golden whole-file normalized diff** (the deferred half of M2's gate): before-file + scripted `place_corner` ×3 with golden radii + scripted fold designation → exported result diffed against the user's after-file per CONTRACTS §4 normalization recipe. Per-corner R: two at 3.175, one at 1.5875 (SAMPLES.md). Fold geometry comes from M5's `resolve_folds`.
5. Gates in one command: `python tools/verify_m6.py <out_path>` = audit clean + version match + original-file SHA256 unchanged + normalized diff report → exit non-zero on any failure. This is the machine-checkable M6 DoD; the human Fusion round-trip (ISSUE-008) remains manual.
