# Brief — M4: Apply All + Undo + Overlap

**Files you own:** `model/snapshots.py` (if not existing), `ui/apply_panel.py`, glue in `app.py`. You consume contracts; edits to `rules/`, `geometry/`, `model/` internals are forbidden (gap >2 loops → STOP, log).

## Scope (SPEC §4.4, §11.7, ADR-001, ADR-009)

1. Apply All: takes every PENDING corner result, applies in click order (`Model.apply_corner` per CONTRACTS), snapshot taken immediately before first mutation. Snapshot stack: unbounded depth (docs are tiny — do not "optimize" memory; the model is <1 MB).
2. Undo: swap to previous snapshot; **multiple undos permitted**; second-to-last disable only at stack empty. Revert-to-Original = swap to load snapshot + clears `flag_decisions` (their stickiness is session-scope; ADR-009).
3. Overlap at confirm time (SPEC §11.7): strict-with-EPS_COINCIDE against all pending+applied dogbones; tangent circles pass. Warn-and-skip: toast + entry in preview summary; the skipped corner returns to PICK_EDGE1 cleanly (no half-state).
4. After Apply All: radius entry remains editable (ADR-005 diameter field); pending previews recompute on radius change; UI disables confirm while any `flags.pending` exist (flag flow completes first).
5. Undo/Revert restores flag decisions that traveled in the snapshot (CONTRACTS §1: `flag_decisions` inside `ModelState`).
