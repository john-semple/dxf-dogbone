# Session 2026-10-08 — File bar replaces the native menubar

> **Status: Completed**

User request (not a milestone brief): the white File strip stuck out against the dark shell. A flat File label on the same color as the window was then hard to find. The chosen treatment is a lighter shelf with a File chip, not a tinted bar and not a custom title bar.

## Pre-change confirms (per AGENTS.md)

- (a) Brief read: `documentation/briefs/UI-UPGRADE.md` (item 3 still said the menu stays a native `tk.Menu` and inherits root colors where Tk allows).
- (b) Contracts section read: CONTRACTS §5 ownership matrix. This pass touches only `ui/theme.py`, `app.py`, and `tests/test_app_open_retarget.py`. No engine, rules, geometry, or model changes.
- (c) pytest pre-change: not re-run as a separate gate before the first edit; the suite was already green in this sitting. Post-change output is below.

## What changed

Windows paints the native menubar white, so `root.config(menu=...)` is gone. The same three commands (Open DXF, Export DXF, Exit) post from a `tk.Menu` under a File chip on the left of the top strip. Alt+F uses that path.

The strip is `TopBar.TFrame` (`bar_bg` `#32343e`), one step above the rail, with the existing separator (`#3a3b45`) along its bottom. The chip is `#3e4250` (hover `#484c58`). The ✕ stays on the right as `BarQuiet.TButton` (muted, same surface as the strip). The bottom-right Export button is unchanged.

A 3px accent tick on the chip, matching the section headers, was tried and removed the same sitting. The row and the chip were then shortened (chip `pady=2`, label `padx=8` `pady=2`, ✕ padding `(8, 2)`).
