# 2026-10-08 — Ctrl+Z undo and Ctrl+Y redo

This note was split out of the flag-card spec. It describes the shortcuts as they are.

Ctrl+Z calls `App.on_undo`. Ctrl+Y calls `App.on_redo`. Those are the same methods as the Undo and Redo buttons, so a shortcut also redraws, restarts the corner pick, refreshes fold checks, and drops a stale trim preview.

Bindings are on the root in `App.__init__`, next to T and Escape: `<Control-z>`, `<Control-Z>`, `<Control-y>`, `<Control-Y>`. Both cases are bound so Caps Lock still works. Each handler returns `"break"` so the key is not also typed into a rail field. With no file open, `workflow` is `None` and the key does nothing. With nothing to undo or redo, the existing toasts still show: "Nothing to undo." and "Nothing to redo."

Tests: `tests/test_ui_undo_keys.py`.
