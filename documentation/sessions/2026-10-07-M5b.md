## Decisions (this session)

1. **FoldFSM is canvas-free** (mirrors M3's WorkflowFSM seam): (state,
   event) handlers over fold_eids + mode + badge; no tkinter import
   anywhere in the FSM's path. Headless unit-tested directly via a
   FakePorts object. The FoldPanel shell binds canvas events and
   converts them to FSM events.
2. **Fold-color rendering at draw time** (M5-plan ruling #4 realized):
   `Viewer.fold_eids` is read in `_create` for Seg entities — designated
   folds draw in FOLD_FG (#facc15) at width 2. This survives the viewer's
   full-wipe redraw (fold_eids is model state, not derived geometry);
   `set_model` copies fold_eids from ModelState so the color persists
   across redraws/undo/restore.
3. **`layer_of` on LoadResult** (not on entities — CONTRACTS §1 entities
   don't carry layer): the eid → layer name map travels in LoadResult
   for the UI's auto-preselect-on-load. Dropped-duplicate eids are
   removed from the map during the merge pass.
4. **Auto-preselect fires once per load** at the UI layer
   (`FoldPanel.on_load` called from `App.open_path` after `set_model`);
   a re-Open destroys + recreates the FoldPanel, re-firing for the new
   document. `set_primitives` (called on undo/restore) refreshes the
   badge count + drops stale eids but does NOT re-fire preselect (the
   once-per-load rule). fold_eids travel in snapshots — undo past a
   preselect restores the pre-preselect state; the rule means no
   REPEATED auto-firing on undo, not that preselect is exempt from
   snapshots.
5. **Mode isolation**: fold mode's canvas bindings are installed with
   `add=True` (the corner workflow's bindings stay untouched). Fold
   mode consumes clicks first (the FSM's `click_world` returns early
   when mode is OFF); the corner workflow only fires when fold mode is
   OFF. The `bind_canvas` / `unbind_canvas` methods gate the bindings
   on the mode toggle.
6. **Box-select threshold** (BOX_SELECT_PX = 5.0 per CONTRACTS §3 note /
   SPEC §11.8.4): the shell records the screen-space press point;
   release computes `hypot(dx, dy)`; ≥5 px → `box_select` (world box),
   <5 px → `click_world` (single toggle). The threshold is screen-px
   (not world-px) per the brief.
7. **Shift-click = click** (identical toggle semantics, both directions
   per brief §1): the FSM's `click_world` takes a `shift` flag but the
   path is identical — no separate shift-only behavior.
8. **`pick_fold_line` uses `point_seg_dist`** (no promotion — folds are
   individual lines, SPEC §4.5); straight LINEs only (arcs/circles/
   points/text never designated). The pick radius matches the corner
   workflow's UI_PICK_PX (10 px ergonomic).
9. **Validation warnings fire at designation time** via
   `validate_fold_against_contours` (the load-time stub stays empty-by-
   construction per its docstring; M5b surfaces designation-time
   warnings via this function — the seam the M5-plan pinned). Warnings
   are non-blocking; never auto-undesignates (SPEC §4.5).
