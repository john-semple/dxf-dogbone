## Decisions (ADR-024 written this session)

1. **M5a = headless engine + export stage; M5b = selection UI.** Phase
   order pinned: M5a first (engine before UI — M2→M3 precedent;
   ADR-022(i) M4c1/M4c2 precedent; ADR-018 M7a/M7b precedent).
2. **The original brief's cut-list escape hatch (resolve_folds → no-op
   returning []) is VOID** (ADR-024(e)): the engine stage is the cheaper
   half and the numeric gate's whole substance; cutting it empties the
   milestone. Cut authority within M5b only (box-select polish first,
   ADR-007 order).
3. **Trim semantics pinned for M5a's CONTRACTS block** (recorded for the
   M5a session to pin formally): one `Trim` per fold eid, `old`/`new` =
   (Pt, Pt) endpoint pairs (Seg semantics per ADR-015(d)); BOTH endpoints
   resolve independently against each dogbone circle; both already on-arc
   within eps → no Trim (the idempotency fixture); extend reach cap =
   2× deletion window (pin the exact constant in tolerances.py or as a
   folds.py module constant with the formula 2 × WINDOW_FACTOR × 2 × r
   recorded — M5a session pins which; ADR-024 leaves it to the sprint
   pin). Kept side = the side whose kept portion's interior misses the
   circle (§11.6 "trim at first circle entry from the kept side" — for
   the WORKED-EXAMPLE geometry the fold approaches from the left, giving
   the (44.7941, 51.2634) golden).
4. **fold_color rendering in M5b** = theme key (grep-clean); the exported
   ACI constant is FOLD_COLOR_CONST = 7 (SAMPLES.md) — the on-screen fold
   color is a theme presentation choice, not ACI 7 on-screen.
5. **Auto-preselect fires once per load** at the UI layer (after set_model);
   a re-Open re-fires for the new document. User changes after the
   auto-pick are authoritative (undo does NOT re-fire preselect; fold_eids
   travel in snapshots — a preselect state IS undoable state, recorded
   as intended behavior: undo past a preselect restores the pre-preselect
   empty set; the "once per load" rule means no REPEATED auto-firing on
   undo, not that preselect is exempt from snapshots).
6. **M5b's near-contour warning surface** = status line, non-blocking
   (SPEC §11.3 case 5 is load-time validation language; at designation
   time the same rule applies by construction — M5b surfaces
   `validate_fold_against_contours` output; never silently un-designates).
